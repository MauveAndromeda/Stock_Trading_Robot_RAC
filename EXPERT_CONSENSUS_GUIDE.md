## Risk Management

### Multi-Layer Protection

#### Layer 1: Pre-Trade Filters
```python
if confidence < 0.80:
    REJECT  # Not confident enough

if consensus < 0.70:
    REJECT  # Not enough agreement

if composite_score < 0.6:
    REJECT  # Weak fundamentals

if volatility > 0.40:
    REJECT  # Too risky
```

#### Layer 2: Position Sizing
```python
# Always 100% but with strict stop loss
position_size = 100%
max_loss_per_trade = position_size * STOP_LOSS_PCT
                   = 100% * 4%
                   = 4% of capital
```

#### Layer 3: Stop Loss
```python
# Hard stop: -4%
if current_pnl <= -4%:
    SELL_IMMEDIATELY

# Prevents catastrophic losses
# Even if wrong 5 times in a row: (0.96)^5 = 81.5% capital remaining
```

#### Layer 4: Take Profit
```python
# Lock in gains at +12%
if current_pnl >= +12%:
    SELL_AND_BOOK_PROFIT

# Don't be greedy, take the win
```

#### Layer 5: Trailing Stop
```python
# Protect profits after they occur
if price_drop_from_peak <= -3%:
    SELL_TO_PROTECT_PROFITS

# Example:
# Buy at $100
# Price rises to $110 (+10%)
# Price drops to $106.70 (-3% from $110)
# SELL at $106.70 = +6.7% profit secured
```

#### Layer 6: Daily Loss Limit
```python
if daily_loss >= -6%:
    STOP_TRADING_FOR_TODAY

# Prevents revenge trading
# Protects against bad market days
```

#### Layer 7: Max Drawdown Circuit Breaker
```python
if portfolio_drawdown <= -15%:
    REDUCE_POSITION_SIZE_TO_50%
    RAISE_CONFIDENCE_TO_85%

if portfolio_drawdown <= -20%:
    STOP_ALL_TRADING
    REQUIRE_MANUAL_REVIEW

# Protects capital in severe market conditions
```
